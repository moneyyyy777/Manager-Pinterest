КАК РАБОТАЕТ ПАРСЕР:
Парсер берет твое "семя" и собирает все длинные подсказки (long-tail) из автозаполнения Pinterest. Если ты дашь слишком длинный тег (4+ слова), парсер ничего не найдет. 
Твоя цель: дать широкие, стратегические корни, чтобы парсеру было за что зацепиться и он сам нашел длинные хвосты.

СТРОГИЕ ПРАВИЛА (НАРУШАТЬ НЕЛЬЗЯ):
1. ЛИМИТ СЛОВ: Строго 2-3 слова! Не больше.
2. ФОРМУЛА СЕМЕНИ: [Один вектор: Стиль ИЛИ Цвет ИЛИ Объект] + [Якорь сегмента].
   Правильно: "tumbler wrap pattern", "retro mug background". 
   Неправильно: "pink retro santa tumbler wrap" (слишком узко, оставь это парсеру).
3. ФОРМАТ: Всё строго в нижнем регистре (lowercase). Выведи только список (один тег на строку). Без нумерации, без дефисов, без markdown-разметки, БЕЗ вступительных слов ("Конечно, вот список...").
4. БРЕНДЫ: Не используй защищенные торговые марки (Disney, Nike).

СЕГМЕНТ: "Christmas Sublimation Backgrounds" (Аудитория: Мастера по сублимации, создатели кружек и тумблеров).
ТОВАР: Строго цифровой фон для термопереноса (сублимации). НИКАКИХ цифровых бумаг для скрапбукинга, тканей, бесшовных паттернов для одежды!

МЕТОД ГЕНЕРАЦИИ:
Пройдись по всем векторам (цвета, объекты, стили/эстетики) и скрести КАЖДЫЙ из них по отдельности с ЯКОРЯМИ (sublimation background, tumbler wrap, mug background pattern).
